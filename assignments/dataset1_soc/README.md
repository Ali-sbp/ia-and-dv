# Датасет 1 — карточки СОК (ML-трек)

Обзор учебной выгрузки карточек СОК в **Taipy**. Срезы по дате создания, критичности, продукту-источнику и состоянию меняют четыре показателя, четыре графика и таблицу. Сброс возвращает весь период. Время показано в UTC.

## Запуск

Из каталога `assignments/dataset1_soc`, Python 3.11:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python download_data.py
python app.py
```

Открыть [http://127.0.0.1:5011](http://127.0.0.1:5011). Если порт занят, передайте `--port 5012`.

Вместо скачивания можно поместить готовый файл `iavd_incidents_raw_target.parquet` в `data/` или передать приложению путь к нему: `python app.py --data /путь/к/файлу.parquet`. Источник — [диск курса](https://disk.yandex.ru/d/waiZmiOzun8EZA) → `1.5 Пр Декомпозиция → Dataset`, полная выгрузка 240 295 × 97, а не выборка из 1 000 строк. Parquet не хранится в Git. Скрипт загрузки сверяет SHA-256.

## Проверка и воспроизведение

1. По умолчанию видно **240 295** карточек. Выбор «Критическая» оставляет **4 079**, «MaxPatrol SIEM» отдельно — **142 549**, «Открытые» отдельно — **164**. Интервал включает обе даты. Нажатие «Сбросить» возвращает полную выгрузку.
2. В таблице показано до 200 наиболее свежих карточек среза, по 10 на страницу; показатели считаются по всему срезу. Составные значения сохраняются в одной карточке. «Открытые» определяются по отсутствию токена «Закрыт» в фазе реагирования.
3. `python eda.py` пересчитает обе Markdown-работы. Параметр `--data` выбирает исходный файл, `--output-dir` — каталог результатов. Для локальной проверки исходных имён используйте `--show-identifiers` вместе с отдельным каталогом вывода вне репозитория.

Вердикты аналитиков описывают обработку карточек. Метрики модели, инференс и XAI относятся к следующим этапам проекта.
