# Датасет 2 — инференс модели (ML-трек)

Интерактивная проверка порогов на учебном журнале предсказаний СОК. [Отчёт и расчёты по обоим заданиям §9](ОТЧЁТ.md) открываются прямо на GitHub.

- Меняйте **порог τ** и **относительную цену пропуска k**. Пересчитываются матрица ошибок, precision, recall, Fβ и стоимость.
- Сравните учебный порог **0,18**, минимум стоимости и максимум Fβ. Кнопки устанавливают рассчитанные пороги точно, включая пороги между шагами ползунка.
- Посмотрите примеры FP и FN с ближайшими к порогу оценками. Лог связан с парной таблицей карточек по `incident_id`.

## Запуск

Из каталога `assignments/dataset2_inference`, Python 3.11:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python download_data.py
python app.py
```

Откройте [http://127.0.0.1:5013](http://127.0.0.1:5013). Порт можно изменить через `--port`.

`download_data.py` скачивает и проверяет SHA-256 двух файлов курса. Их также можно поместить вручную в `data/` или указать каталог через `python app.py --data-dir /путь/к/данным`:

- `MODEL_PREDICTIONS_target.parquet` — лог инференса.
- `iavd_incidents_raw3_target.parquet` — парные карточки для просмотра примеров.

Путь на [диске курса](https://disk.yandex.ru/d/waiZmiOzun8EZA): `3.6_Пр_Интеграция_ML → BI-трек (практика) → Qlik → Data → 3 → Parquet → Gen`. Файлы Parquet не включены в Git. Подкаталог называется BI, но исходные файлы читаются в Python без Qlik.

## Проверка

```bash
python report.py
python -m unittest -v
```

`report.py` воспроизводит отчёт. Тесты проверяют равные оценки, крайние пороги и точный перебор; при наличии данных также сверяют результаты на учебном логе.

Контроль при **k = 4**: при 0,18 матрица **TP 1 331 / FP 2 563 / FN 335 / TN 11 610**. Кнопка «Минимум стоимости» ставит **0,25267** (стоимость 3 364), «Максимум Fβ» — **0,25129** (стоимость 3 365). В метриках 15 839 записей с метками 0 или 1.

Это этап оценки сохранённых предсказаний. Запуск предобученной модели и XAI остаются отдельной частью проекта.
